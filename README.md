# المكتبة الشاملة — قناة التحديث

هذا المستودع يخدم تطبيق أندرويد «المكتبة الشاملة» (`com.alboheth.assistant`).

## التنزيل المباشر
[تنزيل التطبيق (APK)](https://raw.githubusercontent.com/AliHasan122519/Search/main/apk/almaktaba.apk)

بعد التنزيل افتح الملف واسمح بالتثبيت من مصدر غير معروف إن طُلب.

## كيف يصل التحديث إلى المستخدمين
- التطبيق يقرأ `content/manifest.json` من هذا المستودع عند فتحه وكلما رجع إلى الشاشة (مرة كل ربع ساعة كحدٍّ أقصى).
- إذا كان `apk.versionCode` فيه أكبر من إصدار التطبيق المثبَّت ظهرت نافذة «يتوفر تحديث جديد»، فيحمّل التطبيق `apk/almaktaba.apk` ويفتح مثبّت أندرويد، وتبقى بيانات المستخدم.
- يرفض التطبيق أي ملف ليس لنفس الحزمة أو ليس أحدث أو ليس موقَّعًا بنفس مفتاح التوقيع.

## نشر إصدار جديد
من مجلد مصدر التطبيق، بعد رفع `versionCode` في `android/app/build.gradle` (و`VITE_APK_VERSION` في `.env.android`) وبناء الـAPK:
```bash
node scripts/publish_update.mjs android/app/build/outputs/apk/release/app-release.apk <مسار هذا المستودع> "ما الجديد"
cd <مسار هذا المستودع> && git add -A && git commit -m "إصدار جديد" && git push
```
يجب توقيع كل إصدار بالمفتاح نفسه، وإلا لن يقبله أندرويد فوق النسخة المثبّتة.
